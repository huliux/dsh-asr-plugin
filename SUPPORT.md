# Support and contact

## Usage questions, bugs and feature requests

Use [GitHub Issues](https://github.com/huliux/dsh-asr-plugin/issues).
Search existing issues before opening a new one. Include the plugin, DSH, Node.js
and macOS versions, architecture, Desktop or Web mode, steps to reproduce,
and expected and actual behavior. For transcription issues, include the model mode.

Use synthetic audio and content-free diagnostics where possible. Do not attach
meeting audio, transcripts, databases, credentials, signing material or other
personal data. Contribution requirements are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Collaboration and private inquiries

Contact [dasenrising@gmail.com](mailto:dasenrising@gmail.com) for collaboration
or matters that need private discussion. Ordinary usage questions and bugs belong
in Issues so others can find and contribute to the answer.

## Security reports

Follow [SECURITY.md](SECURITY.md) to report suspected vulnerabilities privately.
The project does not guarantee response times or a release schedule.
