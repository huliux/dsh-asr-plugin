# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/huliux/dsh-asr-plugin/security/advisories/new)
to report a suspected vulnerability to the maintainers. If that form is unavailable,
email [dasenrising@gmail.com](mailto:dasenrising@gmail.com) with the subject
`[Security] dsh-asr-plugin`.

Do not disclose vulnerability details in public Issues or pull requests before
coordinating with the maintainers. Ordinary bugs and usage questions use the
channels in [SUPPORT.md](SUPPORT.md).

Include the affected plugin version or commit, DSH, Node.js and macOS versions,
architecture, Desktop or Web mode, expected and actual behavior, potential impact
and reproducible steps. Use synthetic fixtures and minimal, redacted diagnostics.
Do not send real meeting audio, transcripts, databases, credentials, signing
material or other personal data.

## Versions and follow-up

Security reports for the latest stable npm release are prioritized. Reports for
older releases and the development branch are also welcome; identify the exact
version or commit. A patch for every older version is not guaranteed.

Maintainers will assess the report and coordinate remediation and disclosure
with the reporter. The project does not guarantee response times or a release
schedule.
